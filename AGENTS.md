# AGENTS.md

## Project

**AI Expense Audit Assistant** — a full-stack application that helps auditors/managers review employee expense
claims. A multi-agent workflow validates claims against receipt data, business rules, and company policies, and
produces a structured, grounded recommendation.

| Layer | Tech |
|---|---|
| Frontend | Next.js (`apps/web`) |
| Backend | FastAPI (`apps/api`) |
| Database | PostgreSQL + pgvector |
| ORM / driver | SQLAlchemy 2.x / psycopg 3 |
| Migrations | Alembic |
| Agent framework | LangGraph |
| LLM | Google Gemini Flash |

## Ground Rules

Non-negotiable rules. Depth lives in `docs/`.

1. **No business logic in route handlers.** Routers parse/validate and delegate to services/workflows
   (`docs/backend/api-design.md`).
2. **Structured contracts everywhere.** Agents, tools, and services exchange Pydantic models — never loose dicts or
   free-form strings. Define a schema once; do not duplicate it (`docs/schemas/data-contracts.md`).
3. **Deterministic logic stays in code.** Validation rules, totals, date math, required fields, duplicate checks.
   Use the LLM only for reasoning/extraction (`docs/agents/validation-agent.md`).
4. **Agents never touch SQL or database sessions.** They use narrow, well-defined tools. **No `execute_sql`
   tool.** Least privilege (`docs/agents/agent-tools.md`).
5. **All schema changes go through Alembic migrations.** Changing a SQLAlchemy model never changes the DB by
   itself; review migrations, don't blindly trust autogenerated ones (`docs/backend/technology-stack.md`).
6. **No long-lived transactions across LLM calls.** Commit short, deliberate transactions
   (`docs/backend/reliability.md`).
7. **Never commit secrets.** All configuration is environment-driven. LLM output is untrusted until Pydantic-
   validated (`docs/backend/llm-integration.md`, `docs/backend/security.md`).
8. **Errors are first-class workflow states** — explicit failures with context, safe retries only, explicit
   timeouts (`docs/backend/reliability.md`).
9. **The audit result must be grounded and explainable** — recommendation, reasons, findings, policy references,
   warnings, confidence. Decision support, not autonomous approval (`docs/backend/auditability.md`).
10. **No second ORM / framework / driver / vector DB** without an explicit architectural decision
    (`docs/development/code-standards.md`).

## Architecture

Layered:

```text
API → Application/Workflow → Agents → Tools/Services → Infrastructure → PostgreSQL / External services
```

LangGraph workflow orchestrated by the **Audit Agent**. The Validation Agent and Policy RAG Agent run in parallel;
the Audit Agent then runs an **LLM assessment node** that summarises the OCR/validation/policy stage outputs into the
final recommendation (summary, decision, priority, confidence); a deterministic aggregation step remains as the
fallback and envelope builder when that LLM call fails:

```text
Audit Agent → OCR & Extraction Agent → Audit Agent
  → [Validation Agent | Policy RAG Agent]  (parallel)
  → Audit Agent (LLM assessment → aggregate + persist) → Manager/Auditor
```

Per-agent files: `docs/agents/orchestration.md`, `audit-agent.md`, `extraction-agent.md`,
`validation-agent.md`, `policy-rag-agent.md`, `agent-tools.md`.

## Documentation

Start at **`docs/README.md`** — it is the index and maps each file to when to read it. Load the file specific to
the area you're changing; don't duplicate rules from the most-specific file into other files.

- Backend: documented (current source of truth).
- Frontend: **not documented yet** — follow existing Next.js conventions in `apps/web`, keep frontend changes
  localized, and don't modify backend architecture for frontend needs unless an API contract requires it.

## Commands (backend)

```bash
cd apps/api
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app.main:app --reload --port 8000
```

- Interactive docs: `http://localhost:8000/docs`
- Health: `app/api/health.py` (`GET /health`) exists but is **not yet** included in `main.py`.

Tests:

```bash
cd apps/api
.venv/bin/python -m pytest          # asyncio mode auto; tests under apps/api/tests
```
